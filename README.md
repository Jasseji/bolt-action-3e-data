# Bolt Action 3rd Edition – Minimal DAK

Eksperymentalny, fanowski zestaw danych dla NewRecruit/BattleScribe.

## Zawartość

- `Bolt Action Third Edition - Minimal DAK.gst`
- `Germany - Deutsches Afrika Korps - Minimal.cat`
- `Afrika Korps 999 pts.ros`
- `Afrika Korps 999 pts.rosz`

System obejmuje wyłącznie jednostki potrzebne do roboczej rozpiski DAK:
dowódców plutonów, trzy drużyny piechoty, PTR, MMG, średni moździerz,
Flak 88, Sd.Kfz. 251/10 oraz Panzer III L/N.

## Wrzucenie do GitHuba

1. Otwórz repozytorium `Jasseji/bolt-action-3e-data`.
2. Wybierz `Add file` → `Upload files`.
3. Rozpakuj pobrany ZIP na telefonie lub komputerze.
4. Zaznacz i prześlij PLIKI ZE ŚRODKA folderu, nie sam ZIP.
5. Pliki `.gst` i `.cat` muszą znajdować się w katalogu głównym repozytorium.
6. Kliknij `Commit changes`.

## Dodanie w NewRecruit

1. Otwórz NewRecruit.
2. Wejdź w `Add or remove games`.
3. Wybierz `Add from GitHub`.
4. Wpisz:
   `Jasseji/bolt-action-3e-data`
   albo pełny adres repozytorium.
5. Po załadowaniu wybierz system:
   `Bolt Action: Third Edition (Minimal DAK)`.
6. Utwórz nową rozpiskę Germany – DAK.

Dopiero po dodaniu systemu spróbuj zaimportować plik
`Afrika Korps 999 pts.rosz`.

## Ograniczenia

To wersja testowa 0.1. Nie jest pełnym katalogiem Bolt Action 3E.
Punkty są wpisane ręcznie i nie powinny być traktowane jako oficjalnie
zweryfikowane. Struktura plutonów oraz walidacja ograniczeń zostaną
rozbudowane po pierwszym udanym teście importu w NewRecruit.
